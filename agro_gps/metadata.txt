about=Agro GPS is a digital farm notebook (fields, treatments, fertilisation, harvest) ready for the EU electronic plant-protection record. This plugin connects QGIS to it: load the fields of your farm with their crop and area as a polygon layer, click on the map to add the Spanish SIGPAC agricultural parcel at that point (public SIGPAC service of the Spanish Ministry of Agriculture, no key needed), and send selected polygons from any layer to your notebook as new fields. Loading and sending fields uses the Agro GPS web API, an external service run by The Hidden Panda: you need an Agro GPS account and a key created in the app (Settings > API and webhooks); a read key loads fields, a write key also sends them. The SIGPAC lookup works without an account. A satellite basemap (Esri World Imagery) is added only when the project has none. No extra Python packages are needed.
